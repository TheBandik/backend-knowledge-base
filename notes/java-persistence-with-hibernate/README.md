# Кристиан Бауэр - Java Persistence API и Hibernate

Книга посвящена работе с персистентностью данных в Java-приложениях с использованием стандарта JPA и популярной реализации Hibernate.

В ней подробно рассматриваются основы ORM (object-relational mapping), настройка и использование сущностей, управление жизненным циклом объектов, работа с транзакциями и кэшированием. Отдельное внимание уделено написанию эффективных запросов (JPQL, Criteria API), оптимизации производительности и решению типичных проблем, возникающих при работе с базами данных.

Книга формирует системное понимание того, как Java-приложение взаимодействует с реляционной базой данных, и учит не просто использовать Hibernate «по шаблону», а осознанно управлять данными, их загрузкой и сохранением с учетом архитектурных требований.
